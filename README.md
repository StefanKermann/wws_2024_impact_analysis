WWS 2024 Impact Analysis – Apartment Portfolio (1500 units)

Overview
This project analyses the impact of the transition from WWS 2022 to WWS 2024 on a hypothetical portfolio of 1,500 homes. The dataset was created in Python, processed in Excel and visualised in Power BI. The end result is a one-page dashboard (NL/EN) that illustrates rent trends, scoring and risk indicators.

Objectives
•	Build a synthetic apartment portfolio for analysis
•	Understand the financial and regulatory impact of WWS 2024
•	Explore rent development and point scoring
•	Provide a visual summary for decision makers

Tools & Technologies
•	Python (pandas, numpy, matplotlib)
•	Excel (data cleaning & adjustments)
•	Power BI (visualization & measures)
